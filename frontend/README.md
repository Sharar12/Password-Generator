# Password Generator

A secure, client-side password generator built with **Next.js 16**, **React 19**, and **Tailwind CSS 4**.

## Features

- Generate random passwords with configurable length (4–64 characters)
- Toggle character sets: uppercase, lowercase, numbers, symbols
- Exclude ambiguous characters (e.g. `o`, `O`, `0`, `l`, `I`, `1`)
- Password strength indicator (Weak / Fair / Good / Strong)
- One-click copy to clipboard
- Fully client-side — no data sent to any server

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
